# Local Philadelphia source files

This folder holds the unmodified OpenDataPhilly Real Estate Transfers extract.
The main pipeline expects:

- `rtt_summary.csv` — required analytical input;
- `rtt_summary.xlsx` — optional original workbook retained for source review.

Both files are intentionally excluded from GitHub because of their size. Do
not rename, edit, or commit the raw source. If the source is refreshed, record
the download date and rerun the cleaning validation before replacing the
shared team files.
